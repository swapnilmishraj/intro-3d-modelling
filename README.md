# intro-3d-modelling

Beginner-friendly micro-course for 3D modelling and 3D printing.
Uses Tinkercad (browser-based).

## Website

This repo is meant for GitHub Pages.

GitHub Pages URL (after publishing):
- https://swapnilmishraj.github.io/intro-3d-modelling/

Site homepage source:
- [index.md](index.md)

## What you will learn

- How to move around in 3D (rotate / pan / zoom)
- How to add and edit shapes
- How to align and group shapes
- How to export an STL for printing

3D printing builds objects layer by layer.
STL is the file that describes the shape.

## Publish on GitHub Pages

1. On GitHub, open this repo.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**:
	- **Source**: Deploy from a branch
	- **Branch**: `main`
	- **Folder**: `/ (root)`
4. Click **Save**.
5. Wait 1–3 minutes, then open:
	- https://swapnilmishraj.github.io/intro-3d-modelling/

If you see a 404, double-check:
- The branch is correct (`main`)
- The folder is `/ (root)`
- The repo is public (or your plan supports private Pages)
