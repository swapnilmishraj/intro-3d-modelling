# intro-3d-modelling

Beginner-friendly micro-course for 3D modelling and 3D printing.
Uses Tinkercad (browser-based).

## Website

This repo is meant for GitHub Pages.
Open the homepage:
- [index.md](index.md)

## What you will learn

- How to move around in 3D (rotate / pan / zoom)
- How to add and edit shapes
- How to align and group shapes
- How to export an STL for printing

3D printing builds objects layer by layer.
STL is the file that describes the shape.
