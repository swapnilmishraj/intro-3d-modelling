## Goal of This Exercise

By completing this exercise, you will:

- Understand what 3D modelling is
- Learn how simple shapes can be combined to create objects
- Design your first basic 3D model
- Prepare a model that can be 3D printed

You do **not** need any previous experience.

---

## What Is 3D Modelling?

3D modelling means creating objects on a computer that have:

- Width
- Height
- Depth

These objects exist in a **virtual 3D space**, similar to the real world.

You will create models using **basic shapes** like:
- Boxes
- Cylinders
- Spheres
- Text

Complex objects are made by **combining simple shapes**.

---

## What Is 3D Printing?

3D printing is the process of turning a 3D model into a real object.

How it works (simplified):

- A computer sends instructions to a 3D printer
- The printer melts plastic
- The plastic is placed **layer by layer**
- Many layers together form the final object

You will design the model.
The printing will be shown later.

## Tool We Will Use: Tinkercad

We will use **Tinkercad** because:

- It works in a web browser
- It is free
- It is made for beginners
- No installation is needed

Website:
https://www.tinkercad.com

---

## Step 1: Create a Tinkercad Account

1. Open https://www.tinkercad.com
2. Click **Sign Up**
3. Create a free account
4. Log in
5. Click **Create New Design**

You should now see:
- A grid (workplane)
- A toolbar with shapes
- A 3D view you can rotate

---

## Step 2: Learn the Basics (Mandatory)

Inside Tinkercad:

1. Look for **Lessons** or **Tutorials**
2. Complete the beginner lessons:
   - Moving the camera
   - Adding shapes
   - Scaling objects
   - Rotating objects
   - Grouping objects

Do not skip this step.

---

## Step 3: First Exercise – Basic Shapes

Create a new design and do the following:

- Add a **Box**
- Change its size
- Add a **Cylinder**
- Move it on top of the box
- Rotate the cylinder
- Select both objects
- Click **Group**

Goal:
Understand how shapes combine into one object.

---

## Step 4: Main Exercise – Name Plate or Keychain

### Task

Create a **simple name plate** or **keychain**.

### Steps

1. Add a **Box** as the base
2. Resize it to look like a small plate
3. Add **Text**
4. Write your name or initials
5. Place the text on top of the box
6. Resize the text so it fits
7. Select everything
8. Click **Group**

Optional:
- Add a small hole using a **Hole Cylinder**
- This can turn it into a keychain

---

## Step 5: Check Your Model

Before exporting, make sure:

- The model is one solid object
- Nothing is floating in the air
- All parts are connected
- The model looks reasonable in size

---

## Step 6: Export for 3D Printing

1. Click **Export**
2. Choose **STL**
3. Save the file

This file is what the 3D printer will use.
