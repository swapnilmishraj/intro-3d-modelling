# Lesson 4 — Holes and Cutouts

## Goal

Learn how holes work in Tinkercad.
A hole shape can “cut out” part of another shape.

## Time

15–25 minutes

## What you need

- Tinkercad

## Steps

Quick idea

1. In Tinkercad, some shapes can be set to **Solid** or **Hole**.
2. When you **Group** a solid and a hole, the hole subtracts from the solid.

Part A: Make a clean keychain hole

3. Create a new design.
4. Make a small keychain base:
   1. Box: 50 × 20 × 4 mm
   2. Add Text (optional) and place it on top
   3. Align and group the base + text
5. Add a **Cylinder**.
6. Change it to **Hole**.
7. Set the hole size. Example: 5 mm diameter.
8. Move it near the top-left corner (not too close to the edge).
9. Select the base and the hole.
10. Click **Group**.

Part B: Make a simple stamp (cut-out letters)

11. Drag a **Box** for a stamp base. Example: 35 × 35 × 6 mm.
12. Drag **Text** and type 1–3 letters.
13. Change the text to **Hole**.
14. Set text height to 2–3 mm.
15. Push the text into the stamp base (so it cuts in).
16. Select both shapes.
17. Click **Group**.

## Common mistakes and fixes

- Nothing cuts out: Make sure the cutting shape is set to **Hole**.
- The hole did not go all the way through: Make the hole taller, then group.
- Letters look messy: Use fewer letters and make them bigger.
- The stamp is too thin: Make the base 6–8 mm tall.
